========================================
JARVIS Ultimate - Установка
========================================

Благодарим за выбор JARVIS Ultimate!

Перед установкой убедитесь, что:
- У вас Windows 10/11 (64-bit)
- Установлен Python 3.10 или выше (https://python.org)
- У вас есть права администратора

После установки:
1. Откройте файл .env в папке установки
2. Добавьте ваши API ключи:
   - OPENAI_API_KEY (для ChatGPT)
   - OPENWEATHER_API_KEY (для погоды)
   - NEWS_API_KEY (для новостей)
3. Запустите JARVIS через ярлык на рабочем столе

Голосовые команды:
- "Джарвис" - активация
- "Какая погода?" - прогноз погоды
- "Курс доллара" - курсы валют
- "Покажи новости" - последние новости
- "Проанализируй Chrome" - анализ приложения
- "Покажи аватар" - 3D голографический аватар

Поддержка: https://github.com/Lucifer64-ai/jarvis-ultimate/issues
