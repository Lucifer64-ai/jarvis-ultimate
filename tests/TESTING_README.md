## 🧪 Тесты

### Тест 1: Инициализация AgentManager
Проверяет регистрацию всех 5 агентов:
- Web Developer
- Programmer
- Data Analyst
- Designer
- DevOps

### Тест 2: Распознавание задач
Проверяет, правильно ли система определяет, какой агент должен обработать задачу.

**Примеры:**
- "Создай лендинг для кофейни" → Web Developer ✅
- "Напиши Python скрипт" → Programmer ✅
- "Создай дизайн приложения" → Designer ✅
- "Создай Docker файл" → DevOps ✅

### Тест 3: Выполнение задач
Тестирует генерацию кода агентами (без AI, только шаблоны).

### Тест 4: Сохранение файлов
Проверяет работу FileSaver - автоматическое сохранение созданных файлов на диск.

### Тест 5: Голосовые команды
Тестирует команды управления агентами:
- "какие агенты" - список всех агентов
- "история задач" - последние выполненные задачи
- "возможности агента [имя]" - что может конкретный агент
- "статус агента [имя]" - текущий статус агента

## 💡 Примеры использования

### Голосовые команды

```python
# В main.py или через голосовой ввод
jarvis.process_command("какие агенты")
jarvis.process_command("создай лендинг для ресторана")
jarvis.process_command("история задач")
jarvis.process_command("что может Designer")
```

### Программное использование

```python
from agents.agent_manager import AgentManager

# Создаём менеджер
manager = AgentManager()

# Выполняем задачу
result = manager.execute_task("Создай лендинг для кофейни")

# Проверяем результат
if result['status'] == 'success':
    print(f"Создано файлов: {len(result['files'])}")
    for filename, content in result['files'].items():
        print(f"  - {filename}")
```

### С AI интеграцией

Для работы с AI установите переменную окружения:

```bash
export OPENAI_API_KEY="your-api-key-here"
```

Или добавьте в `.env`:

```env
OPENAI_API_KEY=your-api-key-here
OPENAI_MODEL=gpt-4
OPENAI_MAX_TOKENS=2000
OPENAI_TEMPERATURE=0.7
```

## 🔧 Отладка

### Проверка логов

```bash
# Включить подробные логи
export JARVIS_LOG_LEVEL=DEBUG
python main.py
```

### Проверка сохранённых файлов

Все созданные файлы сохраняются в папку `jarvis_output/`:

```bash
ls -la jarvis_output/
```

### Проверка статуса агентов

```python
from agents.agent_manager import AgentManager

manager = AgentManager()
agents = manager.list_agents()

for agent in agents:
    print(f"{agent['name']}: {agent['tasks_completed']} задач")
```

## 🐛 Известные проблемы

### Проблема: AI не работает
**Решение:** Проверьте, что установлена переменная окружения `OPENAI_API_KEY`

### Проблема: Файлы не сохраняются
**Решение:** Проверьте права доступа к папке `jarvis_output/`

### Проблема: Агент не распознаёт задачу
**Решение:** Проверьте ключевые слова в `core/brain.py` (строка с `agent_keywords`)
